# Files

The Files module (`/files`) is the global document library listing every file uploaded across all customer accounts.

**Permissions:** `file:read` to browse · `file:write` to upload · `file:delete` to remove

## Document library

A searchable table of all documents with filename, customer, folder, type, page count, status, uploader, and date.

![Files library](/img/docs/files-01-library.png)

**Row actions:** download · view extraction results · delete (when permitted)

Use this view when you need to find a document without knowing which customer workspace it belongs to. For day-to-day work, most staff use the **Drive** tab inside a customer workspace instead.
