# Quality assurance overview

This section helps **administrators and staff** verify that the platform is working correctly after setup, upgrades, or configuration changes. Use these guides before go-live or when onboarding a new team member.

## Who should use this

| Role | When to use QA guides |
|------|----------------------|
| **Administrator** | After deploying updates, changing roles, or adding subscription plans |
| **Practice manager** | Monthly health check of customer data and extraction pipeline |
| **New staff member** | Walk through checklists during onboarding training |
| **Customer portal contact** | Verify portal access after account creation |

## What to verify

The platform has six main areas. Each has a step-by-step checklist in [Feature checklists](./checklists):

1. **Sign-in and access** — login, permissions, landing pages
2. **Customers** — list, search, onboarding, workspace tabs
3. **Jobs & extraction** — upload, queue, completion, results
4. **Files & drive** — upload, download, folder structure
5. **Reports** — job cost, document volumes, file activity
6. **Settings** — firm profile, users, roles, plans, notifications

## Recommended schedule

| Frequency | Action |
|-----------|--------|
| **After each release** | Run the [Admin smoke checklist](./checklists#admin-smoke-checklist) |
| **Weekly** | Review failed jobs and overdue Companies House deadlines on the dashboard |
| **Monthly** | Export job cost report and reconcile AI usage |
| **On new customer** | Complete [Customer onboarding checklist](./checklists#customer-onboarding-checklist) |

## If something fails

1. Note the exact page URL and what you clicked
2. Take a screenshot of any error message
3. Check [Troubleshooting](./troubleshooting) for common fixes
4. Report to your administrator using [Reporting issues](./reporting-issues)
