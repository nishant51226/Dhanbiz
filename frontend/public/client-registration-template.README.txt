client-registration-template.pdf
================================

Version: bump this note when you replace the file so support knows which layout is live.

Purpose
-------
Master AcroForm PDF for "Client Registration" downloads. The app fills these fields and
flattens the PDF on download. Replace this file with your branded PDF from design **only
if** the AcroForm field names match (or update src/utils/onboardingPdfAcroformMap.ts).

Regenerate dev placeholder
------------------------
From the frontend folder:

  npm run generate:pdf-template

When your PDF uses different internal names (e.g. Text1, Text2)
-----------------------------------------------------------------
Run the app in dev, click Download PDF, open the browser console and expand
"[pdf-fill] AcroForm fields in loaded template" — copy each `name` value.

Then edit `src/utils/onboardingPdfAcroformMap.ts` and set `PDF_ACROFORM_NAME_OVERRIDES`,
for example:

  company_name: "Text1",
  director_name: "Text2",

Use the canonical key on the left (from the lists above) and your PDF's exact `name`
on the right.

QA
--
After replacing the template, open the downloaded PDF in Adobe Acrobat Reader and the
browser viewer to confirm fields appear and text is not clipped.
